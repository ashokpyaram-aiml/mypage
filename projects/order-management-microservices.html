Order Management Microservices

Role: Technology Lead / Solution Engineer | Client: Fidelity Investments | Resource: Infosys - US & India | Period: May 2012 - Jan 2021

Created an integrated order management system using microservices and ServiceNow orchestration, with Kafka enabling realtime communication across procurement, inventory, dispatch, and fulfilment workflows.

  • Used Confluent Cloud Kafka, Confluent REST Proxy, APIGEE, ServiceNow, Spring Boot, Spring Cloud Stream, and Neo4j.
  • Designed Kafka topics for order requests, inventory updates, dispatch, and downstream fulfilment stages.
  • Introduced correlation IDs for end-to-end order tracking and dead-letter topics for failure handling.
  • Improved issue resolution visibility and reduced manual integration risk across microservices and external systems.
